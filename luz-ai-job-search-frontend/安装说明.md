# 律动求职网站测试 - 安装说明

## 推荐打开方式

1. 解压安装包。
2. 双击 `用VSCode打开.bat` 用 VSCode 打开项目。
3. 在 VSCode 终端运行：

```powershell
npm.cmd install
npm.cmd run dev
```

4. 浏览器打开：

```text
http://127.0.0.1:4173/
```

## 快速预览

如果依赖已经安装，可以双击：

```text
打开预览.bat
```

## 离线查看构建产物

安装包内包含 `dist/` 构建产物。若只想看最终静态结果，可以用任意本地静态服务器打开 `dist/`。

## 不包含内容

安装包不包含以下内容：

- `node_modules/`
- `.npm-cache/`
- `.git/`
- `backups/`
- 旧实验目录和旧压缩包

这些内容体积大，或不适合发给另一台电脑。另一台电脑通过 `npm.cmd install` 会根据 `package-lock.json` 安装依赖。
